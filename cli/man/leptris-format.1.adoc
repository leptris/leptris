== NAME
leptris-format - format and pretty-print XML documents

== SYNOPSIS
*leptris format* [_OPTIONS_] _FILE_

== DESCRIPTION
Format and pretty-print XML documents with customizable indentation and whitespace 
handling. The *format* command parses an XML file and outputs it with proper 
formatting, making it more readable for humans or preparing it for processing.

This command is useful for:

* Pretty-printing minified or compact XML
* Standardizing indentation across XML files
* Removing unnecessary whitespace
* Converting between compact and readable formats
* Preparing XML for version control

== OPTIONS

*-o, --output* _FILE_::
    Write output to specified file instead of standard output. If the file exists, 
    it will be overwritten.

*--indent* _N_::
    Set indentation size in spaces. Valid range: 0-16. Default is 2.
    * 0 spaces produces compact output (same as --compact)
    * 2 spaces is the default and recommended for readability
    * 4 spaces is common in many coding styles

*--compact*::
    Remove all unnecessary whitespace. Produces the smallest valid XML output.
    Mutually exclusive with *--indent*.

*--encode* _ENCODING_::
    Set output encoding. Default is UTF-8. Common values: UTF-8, UTF-16, ISO-8859-1.
    Note: Not all encodings may be supported in the current version.

*--format* _FORMAT_::
    Output format. Valid values:
    * *xml* - Standard XML output (default)
    * *json* - JSON representation
    * *text* - Human-readable text tree

*-h, --help*::
    Show help message for the format command.

== ARGUMENTS

_FILE_::
    Path to the XML file to format. Use *-* to read from standard input.

== EXAMPLES

=== Basic pretty-printing
[source,bash]
----
leptris format document.xml
----

Formats the XML with default 2-space indentation and outputs to stdout.

=== Format with 4-space indentation
[source,bash]
----
leptris format --indent 4 document.xml
----

Uses 4 spaces for each indentation level.

=== Compact XML (remove whitespace)
[source,bash]
----
leptris format --compact document.xml
----

Removes all unnecessary whitespace, producing the smallest valid XML.

=== Save to file
[source,bash]
----
leptris format --indent 2 --output formatted.xml document.xml
----

Formats the XML and writes the result to `formatted.xml`.

=== Format from stdin
[source,bash]
----
cat document.xml | leptris format -
----

Reads XML from standard input and formats it.

=== Format and save in-place
[source,bash]
----
leptris format --output document.xml document.xml
----

Warning: This overwrites the original file. Use with caution or make a backup first.

=== Format multiple files
[source,bash]
----
for file in *.xml; do
    leptris format --indent 4 --output "$file" "$file"
done
----

Formats all XML files in the current directory with 4-space indentation.

=== Pipeline with other commands
[source,bash]
----
leptris format document.xml | leptris xpath - "//book"
----

Formats the XML and pipes it to an XPath query.

=== Create compact version for distribution
[source,bash]
----
leptris format --compact source.xml --output dist/source.min.xml
----

Creates a minified version of the XML for distribution or embedding.

== EXIT STATUS

*0*::
    Success - XML formatted successfully

*1*::
    Parse error - input XML is malformed

*3*::
    I/O error - cannot read input or write output file

*4*::
    Invalid arguments - incorrect options or missing file argument

== INDENTATION STYLES

=== Default (2 spaces)
[source,xml]
----
<root>
  <book>
    <title>Example</title>
  </book>
</root>
----

=== 4 spaces
[source,xml]
----
<root>
    <book>
        <title>Example</title>
    </book>
</root>
----

=== Compact (no whitespace)
[source,xml]
----
<root><book><title>Example</title></book></root>
----

== NOTES

=== Whitespace Handling

The formatter preserves:

* Text content within elements (never modified)
* CDATA sections (content preserved exactly)
* Attribute values (never changed)

The formatter modifies:

* Indentation between elements
* Whitespace between tags
* Line breaks for readability

=== Comparison with xmllint

[cols="2,2",options="header"]
|===
|xmllint |leptris format

|`xmllint --format file.xml`
|`leptris format file.xml`

|Fixed 2-space indent
|`leptris format --indent N file.xml`

|No compact mode
|`leptris format --compact file.xml`

|`xmllint --format file.xml > out.xml`
|`leptris format --output out.xml file.xml`
|===

=== Best Practices

* Always make backups before formatting files in-place
* Use consistent indentation across your project (2 or 4 spaces)
* Use *--compact* for production/distribution, readable formatting for development
* Validate XML with *leptris parse --noout* before formatting
