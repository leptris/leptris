== NAME
leptris-validate - validate XML documents

== SYNOPSIS
*leptris validate* [_OPTIONS_] _FILE_

== DESCRIPTION
Validate an XML document against a DTD, RELAX NG schema, or
Schematron schema and report violations.

== OPTIONS

*--dtd* _FILE_::
    Validate against a DTD.

*--rng* _FILE_::
    Validate against a RELAX NG schema.

*--schematron* _FILE_::
    Validate against a Schematron schema.

*-h*, *--help*::
    Show command-specific help.

== EXAMPLES

DTD validation:

    leptris validate --dtd model.dtd input.xml

RELAX NG validation:

    leptris validate --rng model.rng input.xml
