== NAME
leptris - fast XML parser and XPath evaluator

== SYNOPSIS
*leptris* [_GLOBAL-OPTIONS_] _COMMAND_ [_COMMAND-OPTIONS_] [_ARGUMENTS_...]

== DESCRIPTION
Leptris is a high-performance XML parser and XPath 1.0 evaluator written in pure C. 
It provides command-line tools for parsing, validating, querying, and formatting 
XML documents with zero external dependencies.

*Key Features*:

* Fast XML 1.0 parsing with SIMD optimizations
* Complete XPath 1.0 support (27 functions, 13 axes)
* Full XML Namespaces 1.0 specification
* Multiple output formats (XML, JSON, text)
* Compatible with xmllint for common operations
* No libxml2 or external dependencies required

== COMMANDS

*parse*::
    Parse and validate XML documents. Supports multiple output formats 
    and can validate without producing output. See *leptris-parse*(1).

*xpath*::
    Execute XPath 1.0 queries against XML documents. Returns node-sets,
    strings, numbers, or boolean values. See *leptris-xpath*(1).

*format*::
    Pretty-print or reformat XML documents with customizable indentation
    and optional whitespace compaction. See *leptris-format*(1).

*version*::
    Display version information and build details.

== GLOBAL OPTIONS

*-h, --help*::
    Show help message for leptris or a specific command.

*-v, --verbose*::
    Enable verbose output for debugging.

== EXAMPLES

=== Parse and validate an XML file
[source,bash]
----
leptris parse document.xml
----

=== Execute an XPath query
[source,bash]
----
leptris xpath library.xml "//book/title"
----

=== Format XML with 4-space indentation
[source,bash]
----
leptris format --indent 4 document.xml
----

=== Parse from stdin
[source,bash]
----
cat document.xml | leptris parse -
----

=== Get command-specific help
[source,bash]
----
leptris parse --help
leptris xpath --help
----

=== Check version
[source,bash]
----
leptris version
----

== EXIT STATUS

*0*::
    Success - command completed without errors

*1*::
    Parse error - XML document is malformed or invalid

*2*::
    XPath error - XPath expression is invalid or evaluation failed

*3*::
    I/O error - file not found, permission denied, or read/write failure

*4*::
    Invalid arguments - incorrect command-line options or missing required arguments

*5*::
    Memory allocation failure - out of memory

*6*::
    Internal error - unexpected condition (please report as bug)

== NOTES

=== Comparison with xmllint

Leptris provides similar functionality to xmllint with a more intuitive 
command structure:

[cols="2,2",options="header"]
|===
|xmllint |leptris

|`xmllint --noout file.xml`
|`leptris parse --noout file.xml`

|`xmllint --format file.xml`
|`leptris format file.xml`

|`xmllint --xpath '//book' file.xml`
|`leptris xpath file.xml '//book'`
|===

Exit codes are compatible with xmllint for drop-in replacement.

=== Performance

Leptris is optimized for speed:

* XML parsing: ~2-3× slower than Ox, ~2× faster than Nokogiri
* XPath queries: Complete XPath 1.0 (Ox has no XPath support)
* Memory usage: Comparable to Ox (~7% overhead)
