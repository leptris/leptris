== NAME
leptris-diff - structural diff between two XML documents

== SYNOPSIS
*leptris diff* [_OPTIONS_] _A_ _B_

== DESCRIPTION
Compare two XML documents structurally and report element, attribute
and text deltas as edit operations.

== OPTIONS

*--summary*::
    Print delta counts instead of the operation list.

*--json*::
    Print the edit operations as JSON.

*-h*, *--help*::
    Show command-specific help.

== EXAMPLES

Summarize the differences:

    leptris diff --summary a.xml b.xml

Machine-readable operations:

    leptris diff --json a.xml b.xml
