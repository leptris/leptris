= Taurus: High-Performance XML Parser & XPath Engine in C
:toc:
:toclevels: 3
:sectanchors:
:sectlinks:

**libtaurus** is a C99 library providing fast XML 1.0 parsing, complete XPath 1.0 evaluation, event-based SAX processing, and document canonicalization (C14N). It is designed for low-latency, memory-efficient workloads where predictable performance and safe memory handling matter.

== Highlights

* **XML 1.0 parsing** with UTF-8 validation and optional encoding conversion (UTF-16, ISO-8859, Shift-JIS, EBCDIC, and others via iconv).
* **XPath 1.0 engine** implementing all 13 axes, 27 functions, and 15 operators.
* **SAX API** for event-driven streaming on documents that don't fit a DOM.
* **Canonical XML (C14N)** for digital signatures and cryptographic hashing.
* **Pool-based memory model** — every allocation reachable from a document is released in a single `taurus_document_free` call. Zero leaks across the test suite.
* **Recursion depth guard** — deeply nested input is rejected with a parse error rather than crashing.
* **Per-document strict mode** — strict and lenient parsing can coexist in the same thread.
* **Vtable-based dispatch** — adding a new node type is purely additive; no switches to edit.
* **CLI tool** — `taurus parse`, `taurus xpath`, `taurus format`, `taurus version` for command-line XML processing.
* **No required runtime dependencies** — utf8proc and iconv are optional features, not prerequisites.

== Building

[source,bash]
----
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build
----

Build options (all `ON`/`OFF`):

[cols="1,1,4",options="header"]
|===
|Option |Default |Purpose

|`BUILD_TESTING`
|`ON`
|Build the Google Test suite under `test/`.

|`TAURUS_BUILD_CLI`
|`ON`
|Build the `taurus` command-line tool.

|`TAURUS_BUILD_BENCHMARKS`
|`OFF`
|Build performance comparison targets against libxml2 / pugixml.

|`TAURUS_BUILD_MAN_PAGES`
|`OFF`
|Generate man pages from the AsciiDoc sources under `cli/man/`.

|`TAURUS_ENABLE_UTF8PROC`
|`ON`
|UTF-8 validation and Unicode case conversion via utf8proc.

|`TAURUS_ENABLE_ICONV`
|`ON`
|Multi-encoding conversion via iconv (ISO-8859-1, Shift-JIS, etc.).

|`TAURUS_ENABLE_ASAN`
|`OFF`
|Build with AddressSanitizer (`-fsanitize=address`).

|`TAURUS_ENABLE_FUZZING`
|`OFF`
|Build the libFuzzer harness (`test/fuzz/fuzz_parse.c`).
|===

utf8proc is found via the native `utf8proc` CMake config package, vcpkg's `unofficial-utf8proc`, or a bundled module-mode finder. iconv uses CMake's built-in `find_package(Iconv)`.

[source,bash]
----
cmake --install build --prefix /usr/local

== Using the Library

=== Parsing and querying

[source,c]
----
#include <taurus.h>

int main(void) {
    const char* xml = "<root><item>hello</item></root>";

    TaurusStatus status = TAURUS_OK;
    TaurusDocument doc = taurus_parse_string(xml, strlen(xml), &status);
    if (!doc) { return 1; }

    TaurusElement root = taurus_document_root(doc);
    printf("root: %s\n", taurus_element_name(root));

    TaurusXPathResult result = taurus_xpath_eval(doc, NULL, "//item");
    printf("count: %zu\n", taurus_xpath_result_count(result));
    taurus_xpath_result_free(result);

    taurus_document_free(doc);
    return 0;
}
----

=== Serialization and pretty-printing

[source,c]
----
TaurusSerializeOptions opts = { .indent = 2, .xml_declaration = 1 };
char* out = taurus_document_serialize(doc, &opts);
fputs(out, stdout);
taurus_free_string(out);
----

=== SAX event parsing

[source,c]
----
static void on_element(void* ctx, const char* name, const char** attrs) {
    fprintf(stderr, "<%s>\n", name);
}

TaurusSAXHandler handler = {0};
handler.start_element = on_element;

const char* xml = "<root><child/></root>";
taurus_sax_parse(xml, strlen(xml), &handler, NULL);
----

=== Canonical XML

[source,c]
----
char* canonical = taurus_c14n_canonicalize(doc, TAURUS_C14N_1_0, 0);
printf("%s", canonical);
taurus_free_string(canonical);
----

== Memory model

Every byte the parser allocates that ends up referenced by a document lives in the document's pool. `taurus_document_free` destroys the pool and releases everything in one call. There is no other free path.

This applies to:

* Node structs (element, text, comment, CDATA, processing instruction, doctype).
* Node content strings (allocated contiguously with the struct for cache locality).
* Attribute names (interned via the pool's hash table).
* Attribute values (pool-allocated, bypassing interning).
* DTD container, hash tables, and entity declarations.
* XPath function intermediate strings.

Strings returned from public API functions are documented per-function: some are owned by the document (do not free), some are caller-owned (free with `taurus_free_string`).

== Recursion and DoS protection

The parser rejects element nesting deeper than 256 levels with `TAURUS_ERROR_PARSE`. The default cap matches libxml2's `XML_MAX_DEPTH`. Documents at or below the cap parse normally; deeper documents exit cleanly rather than overflowing the process stack.

== Per-document configuration

Strict mode and the parser's behavior can be configured per document:

[source,c]
----
TaurusDocument strict_doc  = taurus_parse_string(strict_xml,  len, &st);
TaurusDocument lenient_doc = taurus_parse_string(lenient_xml, len, &st);
taurus_document_set_strict(strict_doc, 1);
taurus_document_set_strict(lenient_doc, 0);
----

The thread-default set via `taurus_set_strict_mode(int)` is inherited at document creation and can be overridden.

== CLI

The `taurus` binary built under `build/cli/`:

[source,bash]
----
# Parse and round-trip
taurus parse document.xml
taurus parse --format json document.xml

# XPath queries
taurus xpath document.xml "//item[@id='42']"
taurus xpath --count document.xml "count(//item)"

# Pretty-print
taurus format --indent 4 document.xml
----

Reads from files or stdin (`-`). Exit codes: 0 on success, 1 on parse error.

== XPath coverage

The XPath engine implements the full XPath 1.0 specification:

[cols="2,3",options="header"]
|===
|Category |Implementation

|Axes
|All 13 — `child`, `descendant`, `parent`, `ancestor`, `following-sibling`, `preceding-sibling`, `following`, `preceding`, `attribute`, `namespace`, `self`, `descendant-or-self`, `ancestor-or-self`.

|Functions
|All 27 — `string`, `concat`, `starts-with`, `contains`, `substring`, `substring-before`, `substring-after`, `string-length`, `normalize-space`, `translate`, `number`, `sum`, `floor`, `ceiling`, `round`, `boolean`, `not`, `true`, `false`, `lang`, `last`, `position`, `count`, `id`, `local-name`, `namespace-uri`, `name`.

|Operators
|All 15 — `=`, `!=`, `<`, `<=`, `>`, `>=`, `+`, `-`, `*`, `div`, `mod`, `|`, `and`, `or`, and the predicate operators.

|Predicates
|Positional, attribute, boolean, and nested predicates.
|===

== SAX events

The SAX handler struct (`TaurusSAXHandler`) accepts optional callbacks for each parsing event. Set only the events you need; unset callbacks are skipped.

[cols="1,3",options="header"]
|===
|Callback |Fires when

|`start_document` / `end_document`
|Parsing begins and ends.

|`start_element` / `end_element`
|An element opening or closing tag is encountered.

|`characters`
|Text content is parsed. May be called multiple times per logical text node.

|`comment`
|An XML comment (`<!-- ... -->`).

|`cdata`
|A CDATA section (`<![CDATA[...]]>`).

|`processing_instruction`
|A processing instruction (`<?target data?>`).

|`start_prefix_mapping` / `end_prefix_mapping`
|A namespace declaration starts or ends.
|===

== Performance

Taurus is competitive with or faster than libxml2 across the bundled benchmark suite. Representative parse throughput (Apple Silicon, clang -O3, single-threaded, no iconv conversion):

[cols="1,>1,>1,>1",options="header"]
|===
|Fixture |Taurus (MB/s) |libxml2 (MB/s) |Ratio (lower = taurus faster)

|small.xml (218 B)
|115
|48
|0.42x

|attrs.xml (200 KB)
|98
|71
|0.77x

|large.xml (641 KB)
|120
|97
|0.81x
|===

Memory overhead is dominated by the document pool's page allocation. The pool grows on demand and never shrinks within a document's lifetime; pool destroy releases everything at once.

== Dependencies

* **CMake** >= 3.20
* **C99 compiler** (GCC, Clang, MSVC)
* Optional: utf8proc (Unicode), iconv (encoding conversion), Google Test (test suite)

No runtime dependencies when built without utf8proc/iconv.
