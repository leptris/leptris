= CLI Improvements Implementation Plan

1. **C14N Command** - Canonical XML for digital signatures
2. **Indent Character Option** - Tabs vs spaces for indentation

== Completed Features

All three improvements have been successfully implemented:

1. **C14N Command** (`taurus c14n`):
   - Canonical XML 1.0 and 1.1 support
   - `-o, --output FILE` for output redirection
   - `--version VERSION` for C14N version selection
   - Proper exit codes

2. **Indent Character Option** (`--indent-char`):
   - `--indent-char spaces` (default)
   - `--indent-char tabs` - uses 1 tab per level

3. **Line Ending Control**:
   - `--crlf` for Windows line endings (CRLF)
   - `--lf` for Unix line endings (LF, default)

== Additional Fixes

During implementation, the following issues were also fixed:

- **Command help handling**: `taurus COMMAND --help` now correctly shows command-specific help
- **Version option conflict**: `taurus c14n --version 1.1` no longer triggers global `--version`
- **Exit codes**: `--help` returns exit code 0, actual errors return appropriate codes
