# libxslt general test suite

Files in this directory are copied verbatim from the libxslt
project's test suite (tests/general/), used here as behavioral
specifications.

Source: https://gitlab.gnome.org/GNOME/libxslt (MIT License,
Copyright (C) 2001-2002 Daniel Veillard and others).

Copied for conformance testing of libleptris' XSLT 1.0 engine.
Individual cases that depend on libxslt-specific behaviors are
skipped in the runner with the reason recorded there.
